# Zexus

### Public LineRank Community

Zexus is an independent public community platform where people can share their own lines, messages, replies, jokes and thoughts.

Users can publish lines, choose categories, upload a profile picture, attach an optional image, vote on posts and discover the highest-ranked messages.

Zexus is inspired by the visual feel of a premium group-message community, but it is not an Instagram clone and does not connect to or scrape Instagram.

---

## Features

- Public community feed
- User-created lines and messages
- Username support
- Profile picture upload
- Optional post image upload
- Category selection
- Public post publishing
- Upvote system
- Line ranking page
- Search by username or message
- Category filters
- Edit own posts
- Delete own posts
- Anonymous Firebase authentication
- Realtime Firebase Database feed
- Firebase Storage image uploads
- Mobile-first dark premium interface
- Hash-based navigation
- Empty states without fake content

---

## Categories

Zexus currently supports:

- Roast
- Flirting
- Funny
- Savage
- Wholesome
- Random

Flirting content should remain age-appropriate and non-sexual.
